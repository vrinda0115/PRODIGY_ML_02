# PRODIGY_ML_02
Create a K-means clustering algorithm to group customers of a retail store based on their purchase history.

🛍️ Customer Segmentation Using K-Means Clustering

This project applies unsupervised machine learning using K-Means clustering to group customers based on their Annual Income and Spending Score.
By identifying patterns in customer behavior, retail businesses can better target marketing efforts, improve customer experience, and make data-driven business decisions.

📊 Techniques Used

Data preprocessing

Feature selection

Standardization

K-Means clustering

Elbow method for optimal cluster selection

Matplotlib visualizations

🔧 Tools & Libraries

Python

Pandas

Matplotlib

Scikit-learn (KMeans, StandardScaler)
